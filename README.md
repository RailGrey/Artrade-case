# Предсказание выкупа заказа

## Описание

ML-модель для предсказания вероятности выкупа заказа медицинских товаров.
Компания предлагает доставку в ПВЗ и курьером; 95%+ клиентов оплачивают после получения товара.

## Быстрый старт

```bash
uv sync
uv run python main.py --step all
```

## Датасет

- **Источник**: MIPT_hackathon_dataset.csv
- **Размер**: 5383 заказа, 96 колонок
- **Целевая переменная**: `buyout_flag` (True = выкуплен, False = отказ)
- **Распределение**: 81% выкуп / 19% отказ

## Ключевые признаки

1. `contact_LTV` — историческая ценность клиента
2. `lead_price` — стоимость заказа
3. `lead_utm_source` — источник трафика
4. `n_items` — количество товаров в заказе
5. `contact_Город` — город доставки

## Предобработка данных

- Удаление признаков-утечек (временные метки после оформления заказа)
- Удаление ID-колонок (lead_id, contact_id, и др.)
- Обработка пропусков (>50% → удаление, остальное → медиана/мода)
- Кодирование категориальных признаков (LabelEncoder)

## Feature Engineering

- Временные признаки (день недели, час)
- Количество товаров в заказе
- Категории товаров (подушка, матрас, чехол и др.)
- Географические признаки (город, флаги Москва/СПб)
- Признаки скидки и стоимости
- UTM-агрегаты (наличие UTM, CPC/органика)
